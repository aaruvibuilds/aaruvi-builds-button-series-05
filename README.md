## ☁️ The Build

**Button Series 05** transforms a simple upload action into a cinematic cloud-storage interaction.

The interface starts as a minimal project upload workspace containing a video file:

> `aaruvi-motion-system.mp4`

The user presses and holds **Upload**, triggering a sequence where the interface disappears, a cloud appears, and the file physically travels upward into it.

The final state confirms:

> **UPLOADED**

---

## 🎬 The Experience

The interaction follows a complete visual story:

```text
UPLOAD
   ↓
PRESS
   ↓
RELEASE
   ↓
UPLOADING
   ↓
MOVING TO CLOUD
   ↓
FILE FLIES UP
   ↓
CLOUD RECEIVES FILE
   ↓
UPLOADED
```

Instead of instantly changing the button label, the interface visually communicates the upload process.

---

## ✨ Interaction System

### 01 — Idle

The interface presents:

* Project Uploads
* Motion System
* Video file information
* MP4 badge
* Upload button
* Cloud destination

The button begins in its default:

**Upload**

---

### 02 — Press & Hold

When the user presses the button:

```text
Upload → Release
```

The button physically responds through:

* Scale compression
* Vertical movement
* Shape transformation
* Shadow reduction
* Label transformation

This makes the interaction feel tactile rather than static.

---

### 03 — Uploading

Once released, the upload sequence begins.

The button transforms into:

**Uploading**

A loading spinner replaces the normal upload icon.

At the same time, the interface begins transitioning toward the cloud-upload visualization.

---

### 04 — Moving To Cloud

The caption changes to:

**MOVING TO CLOUD**

The original content fades away while the cloud becomes the visual focus.

A video-file card emerges and begins travelling upward.

---

## 📤 File Flight Animation

The uploaded file is represented as a floating document card.

Its motion includes:

* Scale transformation
* Vertical movement
* Rotation
* Fade-in
* Fade-out
* Accelerated travel

The file moves from the interface toward the cloud destination, creating the illusion of an actual upload journey.

---

## ☁️ Cloud Destination

The cloud is constructed entirely with CSS.

It includes:

* Main cloud body
* Multiple cloud puffs
* Cloud label
* Drop-shadow treatment
* Scaled entrance animation

No external cloud image or asset is required.

---

## 💫 Motion Details

The experience combines multiple animation layers:

### Interface Transition

The original content scales down and fades away.

### Cloud Entrance

The cloud grows into view as the upload begins.

### File Movement

The MP4 file travels upward through the cloud zone.

### Data Trail

A vertical gradient trail reinforces the direction of movement.

### Upload Ring

A circular pulse expands from the upload area.

### Particle Burst

Dynamic particles radiate outward during the upload.

### Completion

The final state reveals a circular confirmation mark with a check animation.

---

## 🧠 State-Driven Interaction

The interaction is controlled through JavaScript states.

### Idle

```text
Upload
```

### Pressed

```text
Release
```

### Loading

```text
Uploading
```

### Progress

```text
Preparing Upload
↓
Moving To Cloud
```

### Completed

```text
Uploaded
```

### Reset

The interface automatically returns to its original state after the animation sequence.
